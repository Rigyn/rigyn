# Command controls

This example registers three controls:

- the typed `--example-compact-output` startup flag;
- the `/example-controls` slash command;
- one keyboard shortcut.

Install it from the rigyn source checkout:

```text
rigyn install ./packages/rigyn/examples/command-controls
```

Run `/example-controls` after `/refresh`. Start rigyn with
`--example-compact-output` to change the value that the command reports.
